설정 · API 키

현재 적용된 키는 보안을 위해 마스킹(뒤 4자리만) 표시됩니다. 변경할 항목만 입력 후 저장하세요.

사용법 안내

필지 입력 → 법규 검토 → 규모 산정 → 사업성 검토 → 3D 매스 순서로 진행합니다.

① 필지 입력

지번/도로명 주소를 입력해 검색하면 지적 폴리곤·실제 대지면적·용도지역이 자동 조회됩니다. 여러 필지를 추가해 합필할 수 있습니다.

전면도로 폭·이격거리(북/남/동/서)는 자동 감지되며, 수동 보정도 가능합니다.

② 법규 검토

용도지역별 건폐율·용적률·높이·일조권 사선제한·인접대지 이격을 자동 검토합니다. '적합/별도 확인' 판정과 근거법령을 함께 표시합니다.

주의 — '별도 확인' 항목(도로사선·채광·가로구역별 높이 등)은 지자체 고시·개별 심의 대상이라 참고값입니다. 인허가 전 반드시 관할 구청/건축사 확인이 필요합니다.

③ 규모 산정

층수별 건폐율·건축면적·연면적·전용면적·의무주차·조경면적 시나리오를 제시합니다. 행을 클릭하면 사업성 탭에 자동 반영됩니다.

주의 — 전용률(65%)·층고(3.2m)·주차 원단위는 표준 가정값입니다. 실제는 평면계획·세대구성·용도에 따라 달라지므로 설계안 확정 시 재계산이 필요합니다.

④ 사업성 검토

토지비·공사비·분양가 단가로 총사업비·분양수입·수익성을 개략 추정합니다. 단가는 시세 입력값 기준의 참고 추정입니다.

주의 — 금융비용·설계/감리·제세공과·미분양 리스크 등은 단순화되어 있어 투자 판단의 근거로 삼지 마세요.

⑤ 3D 매스

산정된 규모로 파란색 매스를 생성하고 주변 현황 건물(회색)과 함께 표시합니다. 표시 설정에서 주변 건물·매스 투명도, 배경 지도(위성/일반), 라벨·도로선을 조절할 수 있습니다.

⑥ 계획 설계 (SD ver2)

규모 산정 시나리오를 이어받아 스페이스 프로그램 → 수직 조닝(층별 용도) → 개략 평면을 자동 생성합니다. 코어를 드래그하거나 평면 형식·유닛 모듈을 바꾸면 면적 배분표와 적합성 검토(피난거리·직통계단·복도폭·승강기·전용률)가 즉시 갱신됩니다. SVG/DXF로 저장하고 3D 매스에 조닝 색상을 반영할 수 있습니다.

주의 — 사각형 매스 가정의 자동 배치 초안입니다. 실제 대지 형상·구조·설비·세부 피난 규정 검토는 건축사 확인이 필요합니다.

계획설계 대안 자동 생성

기획설계 데이터(대지·법규·프로그램)를 바탕으로 법적 한도 내 4개 아키타입을 다중목표로 평가합니다 — 분양극대 · 일조조망 · 중정친환경 · 랜드마크(분동)
